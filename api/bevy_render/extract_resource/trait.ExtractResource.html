Expand description

Describes how a resource gets extracted for rendering.

Therefore the resource is transferred from the “main world” into the “render world” in the ExtractSchedule step.

The marker type F is only used as a way to bypass the orphan rules. To implement the trait for a foreign type you can use a local type as the marker, e.g. the type of the plugin that calls ExtractResourcePlugin.
