pub fn from_point_exact( layout: &'a Layout<B>, x: f32, y: f32, ) -> Option<(Self, ClusterSide)>

Returns the cluster and side which is at the specified position in the given layout. If no cluster is under the specified point then None will be returned.

This is usually the expected behaviour when hit-testing clusters for “hover” or “click” functionality.

Source

pub fn from_point( layout: &'a Layout<B>, x: f32, y: f32, ) -> Option<(Self, ClusterSide)>

Returns the cluster and side which is at the specified position in the given layout. If no cluster is under the specified point but the point is within the overall layout area then it will return the nearest.

This is usually the expected behaviour when hit-testing clusers for text selection or caret positioning.
