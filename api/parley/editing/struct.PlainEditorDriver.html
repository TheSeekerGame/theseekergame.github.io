Expand description

A short-lived wrapper around PlainEditor.

This can perform operations which require the editor’s layout to be up-to-date by refreshing it as necessary.

pub fn set_compose(&mut self, text: &str, cursor: Option<(usize, usize)>)

Set the IME preedit composing text.

This starts composing. Composing is reset by calling clear_compose. Alternatively, the preedit text can be committed by calling finish_compose.

The selection and preedit region can be manipulated independently while composing is active.

The preedit text replaces the current selection if this call starts composing.

The selection is updated based on cursor, which contains the byte offsets relative to the start of the preedit text. If cursor is None, the selection and caret are hidden.

Source

pub fn set_compose_byte_range(&mut self, start: usize, end: usize)

Set the preedit range to a range of byte indices. This leaves the selection and cursor unchanged.

No-op if either index is not a char boundary.

pub fn clear_compose(&mut self)

Stop IME composing.

This removes the IME preedit text, shows the cursor if it was hidden, and moves the cursor to the start of the former preedit region.

Source

pub fn finish_compose(&mut self)

Commit the IME preedit text, if any.

This doesn’t change the selection, but shows the cursor if it was hidden.
