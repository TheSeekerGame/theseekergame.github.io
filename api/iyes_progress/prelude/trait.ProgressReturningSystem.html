Expand description

Extension trait to add the APIs for handling systems that return progress.

Required Methods§

Source

fn track_progress<S: FreelyMutableState>( self, ) -> ScheduleConfigs<ScheduleSystem>

Call this to add your system returning Progress to your App

It will create an entry in the ProgressTracker to represent the system. Every time your system runs, the values it returns will overwrite the previously stored values in the entry.

Note: it is OK if your system does not run every frame (for example, if you have run conditions). The value from when the system last ran will be retained until your system runs again.

Source

fn track_progress_and_stop<S: FreelyMutableState>( self, ) -> ScheduleConfigs<ScheduleSystem>

Like track_progress, but adds a run condition to no longer run the system after it has returned a fully ready progress value.

Dyn Compatibility§
