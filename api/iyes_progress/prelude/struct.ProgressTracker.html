Struct ProgressTracker 

Source 
pub struct ProgressTracker<S: FreelyMutableState> { /* private fields */ }
Expand description

The resource where all the progress information is stored.

You can get information about the overall accumulated progress from here. You can also manage the progress values associated with specific ProgressEntryIds.

The internal data is behind a mutex, to allow shared access. Bevy systems only need Res, not ResMut, allowing systems that use this resource to run in parallel.

All stored values are cleared automatically when entering a state configured for progress tracking. You can reset everything manually by calling clear.
