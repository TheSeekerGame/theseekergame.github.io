Struct Progress 

Source 
pub struct Progress {
    pub done: u32,
    pub total: u32,
}
Expand description

Represents the progress that is being tracked.

It indicates how much work has been completed and how much is left to do.

When the value of done reaches the value of total, it is considered “ready”.

For your convenience, you can easily convert bools into this type. You can also convert Progress values into floats in the 0.0..=1.0 range.
