17/// A modifier to apply a force to the particle which makes it conform ("stick")
18/// to the surface of a sphere.
19///
20/// This modifies the [`Attribute::VELOCITY`] of the particle to make it
21/// converge to the surface of the sphere, while keeping its tangent velocity
22/// component unchanged. This modifier gives best results when it's the last
23/// modifier affecting the particle velocity; otherwise subsequent modifiers
24/// might interfere and break the correction factor calculated by this modifier.
25///
26/// # Attributes
27///
28/// This modifier requires the following particle attributes:
29/// - [`Attribute::POSITION`]
30/// - [`Attribute::VELOCITY`]
31///
32/// # Functioning
33///
34/// The modifier applies a correction to the radial component of the particle's
35/// velocity, either to draw it toward the surface if it's within the zone of
36/// influence of the modifier but too far from the surface, or to make it stick
37/// to the surface if it's already in its vicinity.
38///
39/// ![Conform to sphere](https://raw.githubusercontent.com/djeedai/bevy_hanabi/fa23246e8430e0f29ed0a180d8ea6916b3534789/docs/conform-to-sphere.png)
40///
41/// When inside the area of influence defined by [`influence_dist`], particles
42/// are accelerated by the [`attraction_accel`] alongside the radial direction
43/// toward the sphere center. This effectively makes the particle move closer to
44/// the sphere surface. The particle's velocity is clamped by
45/// [`max_attraction_speed`] to prevent it from accelerating infinitely.
46///
47/// Once the particle arrives in the vicinity of the sphere, an more precisely
48/// inside a "shell" area around the sphere surface, the behavior is tweaked a
49/// bit. That shell area is defined as the area at a distance of
50/// [`shell_half_thickness`] from the sphere surface. The attraction
51/// acceleration in the shell area is increased by a [`sticky_factor`], which
52/// prevents fast moving particles from overshooting their target and passing
53/// through the sphere surface to the other side, oscillating around the surface
54/// with each new correction. The shell area effectively acts as a tolerance
55/// area, where particles inside it are considered to be "around" the sphere
56/// surface. This prevents numerical instabilities trying to conform exactly to
57/// the (infinitely thin) surface while also moving tangentially to it. For this
58/// reason, particles inside the shell area are on average located on the
59/// surface of the sphere, but may wobble around this average. For this reason,
60/// it's best to keep the shell thickness tiny, so this wobbling is not visible.
61///
62/// Particles outside of the area of influence are entirely unaffected.
63///
64/// [`influence_dist`]: crate::ConformToSphereModifier::influence_dist
65/// [`attraction_accel`]: crate::ConformToSphereModifier::attraction_accel
66/// [`max_attraction_speed`]: crate::ConformToSphereModifier::max_attraction_speed
67/// [`shell_half_thickness`]: crate::ConformToSphereModifier::shell_half_thickness
68/// [`sticky_factor`]: crate::ConformToSphereModifier::sticky_factor
69#[derive(Debug, Clone, Copy, PartialEq, Hash, Reflect, Serialize, Deserialize)]
70pub struct ConformToSphereModifier {
71    /// The sphere origin (`Vec3`), in [simulation
72    /// space](crate::SimulationSpace).
73    ///
74    /// This is the point toward which particles are attracted.
75    pub origin: ExprHandle,
76    /// The sphere radius (`f32`).
77    ///
78    /// This is the distance from the sphere origin, and defines the surface to
79    /// which particles conform ("stick").
80    pub radius: ExprHandle,
81    /// The influence distance of this attractor (`f32`).
82    ///
83    /// Particles located at a distance greater than this from the sphere
84    /// surface are not affected by this modifier. This effectively limits
85    /// the effect to a sphere of influence with a radius equal to the
86    /// sphere radius plus this influence distance.
87    ///
88    /// Note that particles located inside the sphere are always influenced.
89    ///
90    /// [`radius`]: ConformToSphereModifier::radius
91    pub influence_dist: ExprHandle,
92    /// Acceleration applied to particles to attract them (`f32`).
93    ///
94    /// Particles in the area of influence of the effect are accelerated by this
95    /// value toward the sphere surface.
96    ///
97    /// Note that because this is an acceleration, all particles are accelerated
98    /// identically. If you want the per-particle mass to have an effect on the
99    /// attraction effect, assign to this acceleration a constant force divided
100    /// by the per-particle mass. That way heavier particles will accelerate
101    /// more slowly, having more inertia.
102    pub attraction_accel: ExprHandle,
103    /// Maximum speed of attraction toward the sphere surface (`f32`).
104    ///
105    /// This value clamps the radial speed of particles being attracted toward
106    /// the sphere surface. Any particle with a radial velocity larger than this
107    /// gets immediately slowed down to this value. This prevents particles from
108    /// accelerating infinitely. This effectively simulates some kind of drag
109    /// effect.
110    pub max_attraction_speed: ExprHandle,
111    /// Optional shell half-thickness defining the conforming tolerance (`f32`).
112    ///
113    /// This is an advanced use parameter. Most users can ignore it. If not
114    /// specified (`None`), a default value is assigned which works in most
115    /// cases.
116    ///
117    /// Particles located close to the sphere surface tend to oscillate around
118    /// it, due to the nature of the linear correction applied to the particle
119    /// velocity, and numerical errors. This can cause numerical instabilities
120    /// and visual jitter. To prevent this, the correction factor is smoothed
121    /// out toward zero in a shell around the sphere surface. Inside that shell,
122    /// the velocity correction factor is reduced, which allows particle to not
123    /// strictly conform to the sphere as long as they remain inside this area.
124    pub shell_half_thickness: Option<ExprHandle>,
125    /// Optional "stickiness" acceleration factor (`f32`).
126    ///
127    /// This is an advanced use parameter. Most users can ignore it. If not
128    /// specified (`None`), a default value is assigned which works in most
129    /// cases.
130    ///
131    /// When particles enter the tolerance shell area, the attraction
132    /// acceleration is amplified by this factor to improve the "stickiness" to
133    /// the ideal sphere surface. The default value if not specified is `2.0`.
134    /// Increasing this value makes the particles instantly "stick" to the
135    /// sphere surface, which may be desirable to avoid an "overshoot" effect
136    /// when particles approach the conforming sphere surface too fast, but
137    /// may also look un-natural depending on the effect.
138    pub sticky_factor: Option<ExprHandle>,
139}

162impl Modifier for ConformToSphereModifier {
163    fn context(&self) -> ModifierContext {
164        ModifierContext::Update
165    }
166
167    fn attributes(&self) -> &[Attribute] {
168        &[Attribute::POSITION, Attribute::VELOCITY]
169    }
170
171    fn boxed_clone(&self) -> BoxedModifier {
172        Box::new(*self)
173    }
174
175    fn apply(&self, module: &mut Module, context: &mut ShaderWriter) -> Result<(), ExprError> {
176        let func_id = calc_func_id(self);
177        let func_name = format!("force_field_{0:016X}", func_id);
178
179        context.make_fn(
180            &func_name,
181            "particle: ptr<function, Particle>",
182            module,
183            &mut |m: &mut Module, ctx: &mut dyn EvalContext| -> Result<String, ExprError> {
184                let origin = ctx.eval(m, self.origin)?;
185                let radius = ctx.eval(m, self.radius)?;
186                let influence_dist = ctx.eval(m, self.influence_dist)?;
187                let shell_half_thickness = if let Some(shell_half_thickness) = self.shell_half_thickness { ctx.eval(m, shell_half_thickness)? } else { "0.1".to_string() };
188                let max_attraction_speed = ctx.eval(m, self.max_attraction_speed)?;
189                let attraction_accel = ctx.eval(m, self.attraction_accel)?;
190                let sticky_factor = if let Some(sticky_factor) = self.sticky_factor { ctx.eval(m, sticky_factor)? } else { "2.0".to_string() };
191
192                let attr_pos = format!("(*particle).{}", Attribute::POSITION.name());
193                let attr_vel = format!("(*particle).{}", Attribute::VELOCITY.name());
194
195                Ok(format!(
196                    r##"    // Sphere center
197    let c = {origin};
198    // Sphere radius
199    let r = {radius};
200    // Distance and direction to origin (sphere center)
201    let rel_pos = c - {attr_pos};
202    let origin_dist = length(rel_pos);
203    let origin_dir = normalize(rel_pos);
204    // Signed distance to sphere surface, negative if inside sphere
205    let surface_dist = origin_dist - r;
206    // Influence distance
207    let influence_dist = {influence_dist};
208    if (surface_dist > influence_dist) {{
209        return;
210    }}
211    // Current signed radial speed (normal to sphere surface) toward the sphere center, which needs to be
212    // corrected to conform to the sphere.
213    let cur_radial_speed = dot({attr_vel}, origin_dir);
214    // Signed radial speed (toward the sphere center) at which we'd like to move to stick to the surface.
215    // This is smoothed out to zero as the distance to the surface gets close to zero, to prevent numerical
216    // oscillations around the surface.
217    let shell_half_thickness = {shell_half_thickness};
218    let shell_factor = smoothstep(0., shell_half_thickness, abs(surface_dist));
219    let max_attraction_speed = {max_attraction_speed};
220    let max_radial_speed = sign(surface_dist) * shell_factor * max_attraction_speed;
221    // Delta radial speed to reach the ideal value
222    let delta_speed = max_radial_speed - cur_radial_speed;
223    // Conforming delta speed from attraction acceleration
224    let attraction_accel = {attraction_accel};
225    let sticky_accel = attraction_accel * {sticky_factor};
226    let conforming_accel = mix(sticky_accel, attraction_accel, shell_factor);
227    let conforming_delta_speed = sim_params.delta_time * conforming_accel;
228    // Final impulse clamped by the maximum acceleration speed
229    {attr_vel} += sign(delta_speed) * min(abs(delta_speed), conforming_delta_speed) * origin_dir;
230"##
231                ))
232            },
233        )?;
234
235        context.main_code += &format!("{}(&particle);\n", func_name);
236
237        Ok(())
238    }
239}

241/// A modifier to apply a linear drag force to all particles each frame. The
242/// force slows down the particles without changing their direction.
243///
244/// # Attributes
245///
246/// This modifier requires the following particle attributes:
247/// - [`Attribute::VELOCITY`]
248#[derive(Debug, Clone, Copy, Reflect, PartialEq, Eq, Hash, Serialize, Deserialize)]
249pub struct LinearDragModifier {
250    /// Drag coefficient. Higher values increase the drag force, and
251    /// consequently decrease the particle's speed faster.
252    ///
253    /// Expression type: `f32`
254    pub drag: ExprHandle,
255}
256
257impl LinearDragModifier {
258    /// Create a new modifier from a drag expression.
259    pub fn new(drag: ExprHandle) -> Self {
260        Self { drag }
261    }
262
263    /// Instantiate a [`LinearDragModifier`] with a constant drag value.
264    pub fn constant(module: &mut Module, drag: f32) -> Self {
265        Self {
266            drag: module.lit(drag),
267        }
268    }
269}
270
271impl Modifier for LinearDragModifier {
272    fn context(&self) -> ModifierContext {
273        ModifierContext::Update
274    }
275
276    fn attributes(&self) -> &[Attribute] {
277        &[Attribute::VELOCITY]
278    }
279
280    fn boxed_clone(&self) -> BoxedModifier {
281        Box::new(*self)
282    }
283
284    fn apply(&self, module: &mut Module, context: &mut ShaderWriter) -> Result<(), ExprError> {
285        let m = module;
286        let attr = m.attr(Attribute::VELOCITY);
287        let dt = m.builtin(BuiltInOperator::DeltaTime);
288        let drag_dt = m.mul(self.drag, dt);
289        let one = m.lit(1.);
290        let one_minus_drag_dt = m.sub(one, drag_dt);
291        let zero = m.lit(0.);
292        let expr = m.max(zero, one_minus_drag_dt);
293        let attr = context.eval(m, attr)?;
294        let expr = context.eval(m, expr)?;
295        context.main_code += &format!("{} *= {};", attr, expr);
296        Ok(())
297    }
298}
