Struct WeakWeakHashMap 

Source 
pub struct WeakWeakHashMap<K, V, S = RandomState> { /* private fields */ }
Expand description

A hash map with weak keys and weak values, hashed on key value.

When a weak pointer expires, its mapping is lazily removed.
