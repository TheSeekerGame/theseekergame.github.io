Expand description

Implemented for Components that have an associated Scene, which can be constructed with Self::Props.

In general, developers should not implement this manually. Instead, they should derive it, which also derives Component and adds additional protections and assurances.

See the “Scene Components” section of the module docs to see how this is used in practice.
