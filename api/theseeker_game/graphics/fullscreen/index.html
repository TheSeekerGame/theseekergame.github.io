Module fullscreen 

Source
Expand description

Fullscreen effects. Each owns its shader, uniforms, and targets, and draws through a FullscreenPass from the view’s current image into its next, within the camera’s viewport. The image spans the whole render target, so shaders read it at in.position; in.uv spans the viewport, which is what the camera shows.
