Module foreground_fog 

Source
Expand description

Foreground fog: two animated layers of noise over the view, a rear layer and a detailed one nearer the camera, cleared around tethers and under open sky. The vignette pass draws them; this module owns their settings, their atlases, and the mask tethers protect into.
