  • floaters
    Post processing effect that adds randomly floating particles to the scene. It works by first calculating the particle positions on a set grid relative to the camera, then using that buffer directly in the vertex/fragment shader for rendering, avoiding passing the data through CPU side. The grid and layers are designed to correspond to the compute shader workgroup dimensions, which should reduce the performance impact of the effect.
