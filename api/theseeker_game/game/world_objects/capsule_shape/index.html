Module capsule_shape

Expand description

Capsule pod geometry in the pixel grid of its sprite.

Positions count sprite pixels rightward and downward from the top-left corner of the pod artwork, so every value can be read directly against the image. The pod is symmetric about its vertical axis: span tables list left-half spans [x0, x1), and each span is mirrored into the right half. Rects below the sprite reach down the rail.
