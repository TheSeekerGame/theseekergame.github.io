theseeker_game::game

Module intro 

Source
Expand description

Opening cinematic of a new expedition: the escape pod falls through the dusk sky and crashes into the spawn crater, and the player takes over inside the capsule.

Effect art comes from tools/surface_art/generate.py; the sky it falls past is levelgen::surface_backdrop. The timeline counts game ticks, so it pauses with the game. Gameplay input skips to the reveal; menu input leaves the cinematic paused.
