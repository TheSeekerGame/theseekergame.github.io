theseeker_game::levelgen

Module placement 

Source
Expand description

Depth and geyser biomes, decoration/entity/ore placement, and entity publication.

Rules scan open tiles in row-major order. Around its center, a rule image’s green pixels require terrain, red pixels forbid it, and white pixels require a snow decoration. Every roll hashes the tile, the rule’s order, and the kind’s name, so a seed reproduces its placements.
