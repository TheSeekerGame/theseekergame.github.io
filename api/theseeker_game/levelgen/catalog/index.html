theseeker_game::levelgen

Module catalog 

Source
Expand description

Generation asset libraries and the filename conventions that describe them.

Rule images are named <order>_rule… and apply in ascending order; rules sharing an order keep directory order. A rule name may carry ruleflip-x/ruleflip-y (the pattern also matches mirrored), randflip-x/randflip-y (the placed artwork is mirrored at random), prob<N> (the percent chance to apply, default 100), max<N> (placements per chunk) and size tags such as smallcorner. Placement rule directories are named rules… and may carry mindist-<N> (tiles between placements) and colorrule-<RRGGBB> (the chunk color the rules are limited to). Sprite names may carry size tags, weight<N> (default 100), xoffset±<N>/yoffset±<N> and harvest drops.
