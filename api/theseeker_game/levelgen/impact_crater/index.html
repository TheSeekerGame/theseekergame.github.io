Module impact_crater 

Source
Expand description

The spawn crater before and after the landing cinematic’s impact.

Terrain and collision are always those of the formed crater. A spawn template may have an intact-ground sibling with the same file name in assets/levels/chunks/pre_impact/; only its solid (#000000) pixels are read. Cave directly below the chunk where the intact ground closes an opening is filled too, far enough that no view before the impact reaches past it. That terrain is baked as alternate, initially hidden surface patches that a cinematic shows until the pod lands.
