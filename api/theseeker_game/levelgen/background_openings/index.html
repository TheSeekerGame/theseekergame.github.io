Module background_openings

Expand description

Where the near background opens onto the planes behind it.

The near wall follows the platforms, as the artist’s does: it hugs terrain surfaces with a skin a few tiles thick, leaves others bare, swells into occasional masses beside the terrain, and bridges narrow gaps between platforms. Everything farther from terrain stays open. Openings are never slivers, the near wall never floats or thins to a strand in the air, and small openings are closed.
