Expand description

Exemplar-driven near-background detailing: image analogies on an opening mask.

An exemplar pairs a context (near wall, openings, and solid terrain) with the artist’s IntGrid values for the same cells. Synthesis reads a target context and copies each value from the exemplar cell whose surroundings match best, preferring to continue the copies of already-written neighbours so the artist’s strokes and clusters stay whole. Cells deep inside the wall take its base value and cells deep inside an opening stay empty. tools/backgrounds/synthesis.py details the middle and far planes the same way.
