Module inventory

Expand description

The player’s inventory: equipped and stored skills, passives, and weapons, and the backpack.

A keyboard-driven pixel panel in the capsule style. The inventory action opens and closes it; WASD moves between tabs and wells, F equips or removes the selected item, and X closes it.
