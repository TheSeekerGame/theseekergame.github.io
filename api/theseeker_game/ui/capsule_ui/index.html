Module capsule_ui 

Source
Expand description

The capsule’s terminal and storage: panels projected beside their hotspots.

Each frame redraws the open panel from game state as a pixel canvas, anchored to its hotspot’s composited screen position on the gameplay pixel grid. The station in reach is offered through the toolbar’s interact prompt.
