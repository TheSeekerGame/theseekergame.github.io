Module pixel_font

Expand description

Metrics for the variable-width PixelFont2.png bitmap font.

The atlas holds the 95 printable ASCII glyphs in three rows separated by magenta guides. Each cell includes the glyph’s dark shadow column, so glyph widths already contain letter spacing.
