Module pixel_canvas 

Source
Expand description

Pixel-art UI drawn on the CPU at art resolution and shown as one image.

A canvas is a pure function of the state it presents: callers redraw it and publish the result, which replaces the displayed image only when a pixel changes. Icons and glyphs are copied at their native size, and the image node spans a whole number of physical pixels per art pixel, so every UI pixel lies on the gameplay pixel grid.
