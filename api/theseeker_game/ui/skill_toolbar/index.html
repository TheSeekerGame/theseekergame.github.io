Module skill_toolbar 

Source
Expand description

The skill toolbar, the interact prompt above it, and the captions across the top of the screen: pixel canvases redrawn every frame.

The toolbar frame holds the equipped skills with their cooldowns and stock, and shows health and Alignment through the bar windows cut into its art. Until its key is first pressed, a filled slot shows that key on a tiny keycap above its icon. Captions announce level-ups, warn as Alignment runs low and runs out, and name the inventory key at the first pickup.
